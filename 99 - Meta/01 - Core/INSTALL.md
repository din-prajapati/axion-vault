# Installation Checklist

## Pre-Installation
- [ ] Obsidian v1.0.0+ installed
- [ ] Backup your vault (recommended)

## Plugin Installation
- [ ] Install **Templater** plugin
- [ ] Install **Style Settings** plugin  
- [ ] Install **Dataview** plugin (optional)
- [ ] Enable all plugins

## File Copy
- [ ] Copy `_layouts/` folder to vault root
- [ ] Copy `_bases/` folder to vault root
- [ ] Copy `_templates/` folder to vault root
- [ ] Copy `_scripts/` folder to vault root
- [ ] Copy CSS files from `_styles/` to vault's snippets folder

## Templater Configuration
- [ ] Open Settings → Templater
- [ ] Set Template folder: `_templates`
- [ ] Set Script folder: `_scripts`
- [ ] Enable System Commands
- [ ] Enable Folder Templates (optional)

## CSS Configuration
- [ ] Open Settings → Appearance → CSS Snippets
- [ ] Enable `obsidian-inheritance.css`
- [ ] Enable `style-settings.css`
- [ ] Refresh appearance (Ctrl/Cmd + R)

## Style Settings Configuration
- [ ] Open Settings → Style Settings
- [ ] Find "Obsidian Inheritance System" section
- [ ] Find "Obsidian Inheritance - Vauxhall Style" section
- [ ] Customize as desired

## Verification
- [ ] Create new note using Templater command
- [ ] Select "Project-Template.md"
- [ ] Verify template loads correctly
- [ ] Test layout switching buttons
- [ ] Check CSS styling is applied

## Troubleshooting
If issues occur:
1. Check browser console for errors
2. Verify all files are in correct locations
3. Restart Obsidian
4. Review setup guide in `docs/SETUP_GUIDE.md`

## Success Indicators
✅ Templates appear in Templater command palette  
✅ New notes created with proper frontmatter  
✅ Layout switching buttons work  
✅ CSS styling is visible  
✅ Style Settings panels appear
