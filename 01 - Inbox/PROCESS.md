# 📬 Inbox Processing Ritual
> Every item must leave. Empty = done.

## Weekly Checklist
- [ ] `_quick` — file every item: task → Projects, thought → Permanent, ref → Resources
- [ ] `_links` — read or archive. Not reading it? Delete.
- [ ] `_ideas` — promote worthy ones to `05 - Permanent`. Rest: delete.
- [ ] `_media` — watched/listened? File notes. Not yet? Keep or delete.
- [ ] Inbox count = 0 ✅

## Decision Tree
```
Item arrives →
  Is it actionable?
    YES → Does it take <2 min? → DO IT NOW
          Otherwise → 02 - Projects
    NO  → Is it reference? → 04 - Resources
          Is it an idea?   → 05 - Permanent
          Is it expired?   → DELETE
```
